# Система учёта заявок сотрудников

REST API приложение для управления внутренними заявками сотрудников, разработанное в рамках тестового задания.

## Стек технологий
* **Язык:** Java 17+
* **Фреймворк:** Spring Boot 3.2.x
* **База данных:** PostgreSQL 15
* **Миграции БД:** Liquibase
* **Инфраструктура:** Docker, Docker Compose

## Инструкция по запуску

Приложение полностью контейнеризировано и не требует локальной установки СУБД.

1. Убедитесь, что у вас установлен и запущен **Docker** и **Docker Compose**.
2. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
3. Выполните команду:
   ```bash
   docker-compose up --build
