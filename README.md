# Система учёта заявок сотрудников

REST API приложение для управления внутренними заявками сотрудников, разработанное в рамках тестового задания.

## Стек технологий
* **Язык:** Java 17+
* **Фреймворк:** Spring Boot 3.2.x
* **База данных:** PostgreSQL 15
* **Миграции БД:** Liquibase
* **Инфраструктура:** Docker, Docker Compose

## Инструкция по запуску

Приложение полностью контейнеризировано и не требует локальной установки СУБД.

1. Убедитесь, что у вас установлен и запущен **Docker** и **Docker Compose**.
2. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
3. Выполните команду:
   ```bash
   docker-compose up --build
   ```
4. Дождитесь запуска. Во время первого старта произойдет:
    * Запуск контейнера с PostgreSQL.
    * Накатывание структуры БД через Liquibase.
    * Автоматическое заполнение базы тестовыми данными (1 000 сотрудников и 1 000 000 заявок) с помощью `DatabaseSeeder`. Заполнение занимает около 1-2 минут, об окончании сообщит лог `Database seeding completed!`.

Сервер будет доступен по адресу: `http://localhost:8080`.

## Краткое описание реализованного бизнес-процесса
Жизненный цикл заявки состоит из 3-х этапов:
1. **Новая (NEW)** — статус при создании. Назначены автор и исполнитель.
2. **В работе (IN_PROGRESS)** — заявка принята исполнителем.
3. **Выполнена (COMPLETED)** — заявка успешно закрыта.

**Реализованные бизнес-правила (валидация переходов):**
* Нельзя перевести заявку в тот же статус, в котором она уже находится.
* Нельзя перевести заявку из статуса «NEW» сразу в статус «COMPLETED» (необходимо сначала взять в работу).
* Статус выполненной заявки («COMPLETED») является терминальным и больше не может быть изменён.
